## 1. Алгоритмы и Структуры Данных

### Глава 4: Быстрая сортировка (Quick Sort)
**Главные мысли:**
1. Выбираем pivot (опорный эл.), делим массив на меньшие и большие.
2. Рекурсивно сортируем обе части.
3. **Сложность:** В среднем O(n log n), в худшем O(n^2).
4. **Нюанс:** Худший случай O(n^2) возникает, если массив уже отсортирован, а pivot — крайний элемент. *Решение:* брать случайный pivot или медиану из трех.

### Глава 5: Хеш-таблицы
**Главные мысли:**
1. Хеш-функция превращает ключ в индекс массива.
2. **Коллизии** решаются через chaining (списки) или open addressing (открытая адресация).
3. **Сложность:** В среднем O(1) для поиска/вставки/удаления.
4. **Load Factor:** Отношение кол-ва элементов к размеру таблицы. При его превышении таблица делает resize (пересчитывает хеши).
5. **В C++:** `std::unordered_map` (ключ-значение) или `std::unordered_set` (только ключи).

## 2. Язык C++ (Стивен Прата, Глава 17)

### Binary I/O (Бинарные файлы)
**Главные мысли (C++ подход):**
1. **Заголовочный файл:** `<fstream>`. Классы `ofstream`, `ifstream`, `fstream`.
2. **Режим открытия:** Флаг `ios_base::binary` через побитовое ИЛИ (`|`).
3. **Методы:** `.read()` и `.write()` (копируют «сырые» байты).
4. **Приведение типов:** Адрес приводим к `(char *)`, размер через `sizeof()`.
5. **Проверка:** `.is_open()` и `.close()`.

<details>
<summary><b>Сравнение кода: C vs C++ (Развернуть)</b></summary>

**Подход C (fread / fwrite):**
```c
FILE *f = fopen("data.bin", "wb");
if (f != NULL) {
    fwrite(&value, sizeof(value), 1, f);
    fclose(f);
}
```

**Подход C++ (по Прате):**
```cpp
std::ofstream fout("data.bin", std::ios_base::out | std::ios_base::binary);
if (fout.is_open()) {
    fout.write((char *)&value, sizeof(value));
    fout.close();
}
```
</details>

**Важные нюансы из книги:**
* **Зачем `binary`?** В Windows текстовый режим заменяет `\n` на `\r\n`. Это сломает бинарные данные (например, `double`), если там случайно встретится байт `\n`.
* **Опасность со `std::string`:** `.write()` сохранит указатель на память, а не саму строку. При чтении указатель будет "мусорным". *Решение:* использовать `char[]` или писать длину строки, а затем её символы.
* **Виртуальные функции:** Не сохранять объекты с `virtual` методами. Сохранится `vptr` (указатель на таблицу методов), который при следующем запуске программы будет невалиден.
* **Random Access:** `seekg()`/`tellg()` (чтение), `seekp()`/`tellp()` (запись).

## 3. Практика: Сериализация C-Vector

**Задача:** Сохранить и загрузить кастомный динамический массив (C-style) в бинарный файл.
**Сделано:**
- `vector_save` через `fwrite`
- `vector_load` через `fread`

**Алгоритм сериализации:**
1. Пишем метаданные (`size` и/или `capacity`).
2. Пишем сами данные (`v->data`).
3. При чтении: сначала читаем `size`.
4. Выделяем память (в C это `malloc`/`realloc`, в C++ `reserve`).
5. Читаем массив данных в `v->data`.
6. Обновляем поле `v->size`.
