## Главные мысли
1. malloc возвращает void*
2. malloc не инициализирует память
3. calloc зануляет память
4. realloc может переместить память
5. free освобождает память
6. size - сколько памяти занято
7. capacity - сколько памяти выделено
8. vector.h отделяет интерфейс от реализации.

### Stack / heap

Stack:
- автоматическая память;
- локальные переменные;
- очень быстро;
- память освобождается сама при выходе из функции.

Heap:
- ручная память;
- malloc / calloc / realloc / free;
- память живёт, пока мы сами её не освободим;
- ошибки: leak, use-after-free, double free.

## Ошибки
- Одинарные кавычки для строк – printf('[') передаёт символ (int), а требуется строка (const char*). 
- Повторное объявление переменной – нельзя объявлять int value = 0; несколько раз в одной области видимости.
