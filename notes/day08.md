# День 8: Наследование, виртуальные функции и полиморфизм

## Что сделал
- Создал базовый класс `Shape` и наследников `Rectangle`, `Circle`.
- Изучил разницу между композицией (Has-a) и наследованием (Is-a).
- Реализовал полиморфизм через виртуальные функции.
- Превратил `Shape` в абстрактный класс с чистыми виртуальными функциями.

## Главные мысли
1. **Наследование (Is-a)**: класс-наследник является разновидностью базового класса (Circle является Shape).
2. **Порядок вызова конструкторов**: сначала базовый класс, потом наследник (сверху вниз).
3. **Порядок вызова деструкторов**: сначала наследник, потом базовый класс (снизу вверх).
4. **Виртуальные функции**: позволяют вызывать правильную реализацию метода через указатель на базовый класс (динамическое связывание).
5. **Абстрактные классы**: классы с чистыми виртуальными функциями (`= 0`), объекты которых нельзя создавать.

## Что было сложно

## Ошибки и инсайты
- **Инсайт**: Если метод просто вычисляет значение (как площадь), его не нужно хранить в поле - достаточно метода.
- **Важно**: Деструктор базового класса ОБЯЗАН быть виртуальным, иначе при удалении через указатель на базу не вызовется деструктор наследника.
