## Главные мысли

### Захват переменных
1. **Захват по значению `[=]` или `[var]`**: лямбда создаёт **копию** переменной. Изменения оригинала не влияют на лямбду. Захваченные копии константные по умолчанию.
2. **Захват по ссылке `[&]` или `[&var]`**: лямбда работает с **оригиналом**. Может изменять внешнюю переменную. Видит актуальные значения.
3. **Смешанный захват**: `[=, &x]` — всё по значению, кроме x (по ссылке). `[&, x]` — всё по ссылке, кроме x (по значению).
4. **Глобальные переменные не захватываются**: они доступны напрямую из любого места программы, так как существуют всё время выполнения.

### Mutable лямбды
5. **`mutable`** позволяет изменять захваченные **по значению** переменные внутри лямбды.
6. Изменяется **копия** внутри лямбды, а не оригинал снаружи.
7. Лямбда с `mutable` и захваченными переменными — это по сути **маленький объект** со своим состоянием.
8. При копировании лямбды — копируется и её состояние.

### Практические паттерны
9. **`std::for_each`** передаёт каждый элемент диапазона в лямбду как аргумент `(int n)`.
10. **`std::count_if`** сам считает элементы, для которых лямбда возвращает `true`.
11. **`std::sort`** с лямбдой: функция должна возвращать `true`, если первый аргумент должен стоять **перед** вторым.
12. **`std::max_element`** возвращает итератор на максимальный элемент.
13. **`std::remove_if` + `erase`**: стандартный паттерн удаления элементов по условию.

## Ошибки и инсайты
- **Ошибка:** Пытался изменять объект через `const Employee& e` в лямбде → компилятор запрещает. Нужно убрать `const`, если собираемся изменять.
- **Инсайт:** Захват нужен только для локальных переменных, которые иначе были бы недоступны.
- **Инсайт:** `mutable` создаёт лямбду с внутренним состоянием — это как мини-объект.
